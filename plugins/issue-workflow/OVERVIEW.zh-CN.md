# GitHub 议题工作流

创建 Paseo 工作区时可以选择 GitHub 议题。Paseo 会在议题分支上创建工作树，并将议题标题、网址和描述随提示提供给第一个代理。之后也可以把议题附加到提示中，或在工作区面板中查看议题及匹配的拉取请求。

守护进程和应用均需使用 Paseo 0.16.0-beta.1 或更新版本。通过 Git 安装需要 Node 和 npm。Paseo 项目的 `origin` 必须位于 `github.com`。公开议题无需凭据。要访问私有仓库或获得更高的 API 限额，请在守护进程中设置 `GITHUB_TOKEN`。插件读取已注册项目的 Git 远程地址，查询 GitHub API，并在工作区和代理元数据中保存大小受限的议题快照。

拉取请求查找以当前工作区分支和仓库所有者为条件。插件不会创建或关闭议题或拉取请求。它支持 GitHub.com。
