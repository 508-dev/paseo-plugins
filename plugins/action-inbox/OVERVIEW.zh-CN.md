# 行动收件箱

在已连接的 Paseo 在线主机中查看代理的待答问题、工具审批和待审查工作。可按主机、项目或未读状态筛选。**显示失败项**默认关闭，并显示当前筛选范围内隐藏的未读失败数量。隐藏的失败项仍为未读，且不计入侧边栏和批量**全部标为已读**操作。

子代理默认隐藏。开启 **显示子代理** 即可查看。

需要守护进程和应用均为 Paseo 0.16.0-beta.1 或更新版本。通过 Git 安装时，守护进程需要 Node 和 npm。插件仅需安装在一台已连接的主机上，便可通过应用的现有连接查看其他主机的数据。侧边栏或收件箱打开期间，每 20 秒刷新一次，每台主机最多读取 1,000 个活跃代理。

已读状态保存在当前设备上，应用重新加载后仍会保留最近 5,000 条标记。打开代理或使用已读控件即可标记。更新后的请求和新完成的工作会重新显示为未读。标记已读不会处理或回答请求。

问题会预览文本和选项，并打开 Paseo 的原生回答界面。工具请求会先显示完整详情，确认请求未变更后才允许直接操作。较长的请求和非工具请求会打开原生代理界面。离线主机会列出名称，插件不会显示其过期状态、重启失败的运行或排队等待离线操作。
