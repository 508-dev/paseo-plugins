操控在 Paseo 主机上运行的浏览器，或通过现有连接将主机上的开发站点转发到本地浏览器。**主机浏览器**面板会串流 Chrome 画面，并转发指针、键盘、滚动及触摸输入。插件运行期间，每个工作区拥有独立的浏览器上下文。

应用和守护进程均需 Paseo 0.16.0-beta.1 或更新版本。主机还需 Node 22 或更新版本以及 Chrome 或 Chromium。可通过 `PASEO_BROWSER_EXECUTABLE` 指定非默认安装路径。`puppeteer-core` 不会下载浏览器。原生客户端提供触控手势和键盘输入，实体设备和输入法行为尚未验证。

开发站点转发工具在查看端电脑上运行，提供临时回环网址。它支持 HTTP 和 WebSocket，并保留站点内容。查看端需要 Node，手机端尚未集成。授权客户端可以选择主机的任意 IPv4 回环端口，包括工作区脚本以外的端口。

浏览器和转发流量使用选定的 Paseo 连接。直接连接采用其自身的安全配置，已配对的中继连接使用端到端加密。插件不在主机上打开入站端口，也不更改中继配置。浏览器上下文在插件重启时重置，断开连接或归档工作区时会关闭相应的流和隧道。完整桌面界面、iOS 和 Android 实体设备以及生产中继环境尚未验证。
