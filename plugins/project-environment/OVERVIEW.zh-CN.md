在命令中心打开**项目环境**，即可在**项目默认值**中保存共享环境变量，或通过**工作区变量**为当前工作区保存变量。Git 工作树共享项目默认值。同名工作区变量优先，移除后恢复项目值。侧边栏的**环境变量**可按名称或描述搜索当前主机上的项目和活跃工作区。项目默认值在工作区关闭后仍可搜索。

代理可列出变量的名称和描述，也可执行使用指定变量的 shell 命令。命令执行时才读取变量，编辑后无需重开会话。新代理会自动获得工具及使用说明，已有代理需要更新一次 MCP 配置。普通的模型提供商 shell 命令和已有终端不会注入这些变量。

需要 Paseo 0.13.2 或更新版本以及 macOS 或 Linux 守护进程。变量以明文 JSON 存放在项目之外的 `$PASEO_HOME/plugin-data/project-environment`，目录和文件仅所有者可访问。列表和搜索只返回元数据。**显示**和**复制**按需读取单个值，显示的值会在 30 秒后或关闭界面时隐藏。卸载后仍会保留已保存的值，如需删除，请在卸载前通过面板操作。

命令以守护进程用户身份在工作区运行，可访问主机文件系统和网络。命令只接收所请求的已保存变量和基本 shell 环境变量。每条命令最多运行两分钟，支持四个并发 MCP 请求，输出总量上限为 1 MiB。后台服务和交互式输入不受支持。

返回的输出会将与已保存变量完全匹配的值替换为 `[REDACTED]`。已停止命令的输出不会返回，编码或变换后的值无法识别。命令可以写入或发送凭据，也可使用凭据调用 API。返回的 API 响应会进入代理对话，并可能发送给模型提供商。

MCP 代理仅监听回环地址，拒绝来自浏览器的请求，并为不同工作区目录分配独立的随机访问网址。拥有该网址且能访问本地主机的人可调用工具。守护进程用户、管理员及拥有同等文件访问权限的代理可读取变量和访问凭据。
